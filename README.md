# TeachAnalysis
Доказательство основной аксиомы технического анализа "Случайности закономерны"("История повторяется") 

## Краткое описание исследования
Была идея, согласно которой паттерн графика цены акции имеет свойство повторяться. В приложении достаточно выбрать компанию, точку и длину паттерна до точки, программа найдет все места так или иначе похожие на хвост и отрисует их от точки, подсветив настоящий график функции. На самом деле проект был сделан шутки ради, но думаю его можно будет развивать в ближайшее время для более точного расчета соответствия хвоста с паттернами акции. 

## Запуск
Для запуска проекта установите все зависимости из requerements.txt и выполите в терминале следующую команду:

```streamlit run app.py``` 

Запустится локальный сервис с доступом к приложению по адресу  http://localhost:8501
